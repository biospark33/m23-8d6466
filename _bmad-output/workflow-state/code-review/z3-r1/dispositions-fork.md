| E-6 / B-3 / A-4 (crash window, fork part) | PATCH (observation point) / no fork hook | SC2.6 (`tests/fleet/e2e/sc2-6-lease-kill.live.test.ts`) did not catch the window by polling. The same approach works here with no fork code. The factory installs a wrapper that holds `submit` only for the `w:z3-*-code` workId (QA legs pass straight through) and waits on a gate file. The driver polls `state` until `factoryState['z3-code-run']` is `submitting` with a `requestId`, kills the container, releases the gate and restarts.
